# ebay-privacy
Privacy policy for the eBay Developer application.

Data Collection
This application is for personal use to automate my personal eBay store. It only accesses the specific data that the user explicitly authorizes through the eBay OAuth process (e.g., order history, current listings, inventory details).

Data Usage
The data retrieved from eBay is used solely for the automation purposes described in the application's scope. We do not sell, trade, or share your data with third parties. All data is processed in a secure environment intended only for personal tools and operations.

Data Retention
Any data used during the execution of the automation scripts is processed in real-time or stored temporarily in a local, secure environment for the duration of the operation. No personal information is retained on long-term external databases.

Third-Party Services
The only third-party service involved is eBay, which provides the data you explicitly authorize the application to access to function as intended.

If you have any questions regarding this policy, please contact the developer directly via the official communication channels supported by the application.
